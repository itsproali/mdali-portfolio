# Blog posts

One MDX file per post. The filename (minus `.mdx`) is the URL slug.

## Frontmatter

```yaml
---
title: "Post title"
summary: "One or two sentences shown in listings and as the meta description."
date: "2026-06-18"        # YYYY-MM-DD, used for ordering
tags: ["AWS", "Remotion"] # shown as chips
draft: false              # true = visible in `pnpm dev` only
---
```

## Notes

The three posts currently here were drafted from Mohammad's shipped work as
starting points — **read them through and edit them into your own voice before
the site goes live.** Set `draft: true` on anything you're not ready to publish,
or just delete the file.
